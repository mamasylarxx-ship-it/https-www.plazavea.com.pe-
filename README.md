# Mi Mundo Perruno (Web estática)

Este sitio ya está listo para usar y personalizar.

## Verlo en local

```bash
python3 -m http.server 8080
```

Abre: `http://localhost:8080`

## Publicarlo y obtener tu link (gratis)

### Opción A: Netlify
1. Crea una cuenta en Netlify.
2. Arrastra esta carpeta al panel de "Deploy".
3. Te dará un link tipo `https://tu-sitio.netlify.app`.
4. En Settings > Domain management, conecta tu dominio propio.

### Opción B: Vercel
1. Sube este proyecto a GitHub.
2. Importa el repo en Vercel.
3. Obtendrás un link tipo `https://tu-sitio.vercel.app`.
4. En Domains, agrega tu dominio personalizado.

## Qué editar rápido
- Nombre de marca: `index.html`
- Colores y diseño: `styles.css`
- Mensajes y comportamiento: `script.js`
